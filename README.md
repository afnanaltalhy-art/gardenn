# فريق التحقيق البيئي: مهمة إنقاذ

تصميم وإعداد د. أفنان الطلحي
الابتدائية الأولى بصخيبرة

مبنية على عرض «التغيرات في الأنظمة البيئية» للصف الرابع الابتدائي، وتتضمن البراكين والأمطار الغزيرة والجراد والتماسيح وإزالة الغابات والاكتظاظ السكاني والتلوث وحماية البيئة والمواءمة والانقراض.

لعبة عربية بسيطة: اسم الطالبة، ١٠ أسئلة، ثم شهادة باسمها ودرجتها.

## الرفع على GitHub Pages
١. فكّي ضغط الملف ZIP على جهازكِ.
٢. ارفعي جميع الملفات المستخرجة إلى جذر المستودع، بحيث يكون index.html ظاهرًا مباشرة، لا داخل مجلد إضافي. لا ترفعي ملف ZIP نفسه فقط.
٣. فعّلي GitHub Pages للمستودع من فرع main ومجلد الجذر root.
٤. افتحي الرابط الذي يعرضه GitHub بعد اكتمال النشر.

الصور والخطوط مضمنة، والمسارات نسبية وتعمل داخل مسار المستودع.
لا يحتاج المشروع إلى تثبيت حزم أو عملية بناء أو مفاتيح API.
لا يحتاج زوار النسخة المنشورة على GitHub Pages إلى تسجيل الدخول.
اسم الطالبة والدرجة يبقيان في جلسة متصفحها، ولا يرسلان إلى خادم ولا تحفظ المعلمة نتائج الطالبات مركزيًا.
زر طباعة الشهادة يفتح حوار الطباعة؛ يمكن اختيار الحفظ بصيغة PDF إذا كان متاحًا على الجهاز.

## الملفات
index.html — الصفحة
app.js — الأسئلة ومنطق اللعبة
style.css — التنسيق والخطوط والطباعة
mascot.png — الشخصية
ministry.png — شعار الوزارة المرفق
ملفات ttf — الخطوط المحلية

للتجربة المحلية يمكن فتح index.html مباشرة في المتصفح.
